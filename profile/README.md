## AI的名字挂得响，AI的钱是一点舍不得花

中创教育AI，光看名字，科技感倒挺足。到了实际干活，需要用AI工具、需要额度、需要投入的时候，钱包立刻焊死，抠门精神当场拉满。

老板这个傻逼，仿佛只要员工足够努力，模型就能自己推理，额度就能凭空长出来，工具费用就能被意志力抵消。

既想要AI带来的效率，又舍不得给AI花钱，这个算盘打得真他妈响。

**要成果的时候胃口比天大，掏工具费的时候抠得像在割肉。靠这套抠逼逻辑做技术，算力没增加，笑话倒是产出不少。**

技术研发需要资源。你把投入抠掉了，缺口就落在干活的人身上：花更多时间折腾，拿个人精力填坑。真他妈会省，省到最后，成本全长在别人身上。

## 六千块的待遇，怎么长出了一个部门的胃口？

我参与推进和处理过的工作，涉及AI销售客服、企业云盘、联系方式采集、获客短链、设备管理与安卓OCR、运营助手、微信小程序、管理后台、视频工具、内部门户、微信协议研究，以及本地网页工具、产品资料和定价测算。

前端、后端、数据库、接口、测试、打包、排障、文档，工作铺了一大摊。

我不会把研究中的东西吹成成熟产品，也不会把尚待联调的部分说成全部交付。进度能据实说明，问题能逐项列出来，投入过的劳动同样有记录。

**六千块的月薪，工作范围倒像批发来的。老板使唤起技术人员毫不手软，付钱的时候却抠得像银行卡里装着他的命。**

待遇低，要求倒不低。按我上面写明的收款情况，这点约定工资，我还一分没见到。

你这副又想少花钱、又想多拿成果的吃相，真他妈难看。我的劳动，凭什么替你的狗屁经营水平买单？

## 部门准备做软件开发，你张口就说“不正规”？

![虚构乌龟老板用否定符号打断软件方案，熊猫开发人员一脸无语](https://github.com/zhongchuangEDU-AI/.github/blob/main/software-roast.png)

部门准备做软件开发，被你一句“不正规”打回来。老板，你这个傻逼，判断依据到底是什么？

开发流程、交付要求、质量标准，哪一项有问题，就具体指出来。把依据和改进要求说清楚，才方便干活的人落实。

甩出一个标签，就以为自己完成了管理，真够省事的。按我的观感，你这套狗屁评判最荒唐的地方，就是标准全藏在自己脑袋里，却要别人替你的含糊承担后果。

**你那张嘴一张一合，项目就被盖了个“不正规”的章。老板当成这样，管理成本省了，胡说八道的空间倒挺大。**

技术问题拿技术依据说话。光靠坐在老板的位置上摆架子，撑不起你这副到处指点的派头。

## “正规”这把尺子，也拿去量量销售承诺

![虚构乌龟老板对技术工作用大尺子，对自己用小尺子，讽刺双重标准](https://github.com/zhongchuangEDU-AI/.github/blob/main/double-standard-roast.png)

软件开发要讲正规，公司销售承诺就更该拿同一把尺子量。我对销售承诺和实际交付是否一致，同样有质疑。

承诺是否准确、能力是否具备、条件有没有讲清楚，都应该逐项摆出来。

**老板，别他妈把标准用成随手拍人的板砖。轮到你自己负责的经营环节，也请拿出挑技术人员毛病的认真劲。**

一套能公开说明、前后一致的标准，至少比你的个人好恶有用。你要是连依据都讲不清，这副指导工作的派头，在我看来就是个笑话。

对技术部门一句“不正规”就能扣下来，对销售承诺却不该只靠态度糊弄。你既然把“正规”挂在嘴边，就请把它落实到整个公司。

## 承诺说了什么，兑现到哪一步，都摆出来

![原创销售承诺讽刺漫画：夸张的礼盒想象与需要逐项落实的交付清单](https://github.com/zhongchuangEDU-AI/.github/blob/main/sales-promises-roast.png)

销售承诺涉及谁来交付、什么时间交付、有哪些条件，理应经得起核对。承诺时说得多漂亮，不能替代最后的实际结果。

我的要求很具体：把承诺内容、实际交付和存在的差异逐项列清楚，该解释的解释，该处理的处理。

**嘴皮子一翻就能说的话，真要兑现，靠的是能力和投入。老板，少拿你那套狗屁派头替代具体交代。**

你评判技术人员时那么有威风，也拿出同样的劲头，把自己负责的销售和交付标准讲明白。公司经营要经得起核对，老板这个头衔不会自动让你的做法变得正确。

## 学员提出的问题，也请拿出具体回应

我对这种管理的评价很简单：**狗屁不通。**

老板，连自己这一摊都没管明白，还摆什么运筹帷幄的架子？这副派头在我眼里，只剩滑稽。

**傻逼管理最烦人的地方，就是自己制造混乱，却让干活的人承担混乱的成本。**
