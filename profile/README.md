**湖南中创教育科技有限公司**（简称“中创教育”）成立于2014年7月7日，总部位于湖南省长沙市，是一家深耕教育领域十九载（截至2026年）、以“用心服务”为办学理念，致力于通过科技创新赋能学员成长的综合性教育科技企业。

## 📖 关于我们

中创教育以培养社会所需的应用型人才为中心，坚持“以需求为导向、以服务为根本、以特色求发展、以质量求生存”的办学方针。公司不仅与多所知名高校建立了长期稳定的教学点合作关系，更在2022年获评“国家高新技术企业”，将科技创新深度融入教育服务全流程。

## 🚀 核心业务与技术

公司主营业务涵盖自学考试教育、成人学历教育、职业资格培训等领域。截至2023年，公司在籍学生已超过7000人。我们不仅提供教育内容，更通过自主研发的技术平台提升学习体验。

### 技术栈与平台
*   **智能教学SaaS平台**：自主研发，实现教学流程数字化管理。
*   **云课堂系统**：为学员提供灵活、高效、随时随地的在线学习支持。
*   **全周期服务体系**：构建覆盖“报考 -> 学习 -> 毕业 -> 发展”四大阶段的闭环支持系统。

### 业务生态
*   🎓 **在线教育**：提供灵活便捷的远程学习方案。
*   💼 **职业培训**：针对市场需求，开展各类职业资格与技能认证培训。
*   🔬 **技术研发**：持续投入教育装备、软硬件及网络系统工程的技术开发。

## 🏆 里程碑与荣誉

*   **2014年**：公司正式成立，开启教育服务之旅。
*   **2017年**：投资成立湖南欢腾教育咨询有限公司，拓展业务版图。
*   **2022年**：
    *   获评 **“国家高新技术企业”**。
    *   与衡阳师范学院、武汉科技大学等多所高校确立校外教学点合作。
*   **2025年**：
    *   成功备案为长沙市芙蓉区 **“高校毕业生就业见习基地”**。
    *   承办“湖南-东盟职业教育产业合作座谈会”，展现行业影响力。
    *   投资成立湖南省中科创国际大健康技术中心（有限合伙）。
*   **2026年**：持续稳健运营，深化“互联网+教育”战略布局。
